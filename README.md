# koreak9king.github.io (도메인 루트용 저장소)

안드로이드 앱(TWA)이 주소창 없이 전체 화면으로 열리려면
`https://koreak9king.github.io/.well-known/assetlinks.json` 이 있어야 합니다.
게임 저장소(`customs-k9-game`)는 `/customs-k9-game/` 아래에 있어서 도메인 루트에 둘 수 없으므로,
GitHub에 **`koreak9king.github.io`** 라는 이름의 공개 저장소를 새로 만들고 이 폴더 내용을 올립니다.

- `.nojekyll` : GitHub Pages가 점(.)으로 시작하는 폴더를 숨기지 않게 합니다. 꼭 같이 올리세요.
- `index.html` : 루트 주소로 들어오면 게임으로 보냅니다.
